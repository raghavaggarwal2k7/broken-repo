## Problems found with the repository:
 - There was a readme file intended but it was named as Intro.md and hence github doesnt show it by default, does is a bad practice.
 - The the readme that was even made was very vague, as it only had the title and a very very basic description of the repository. A readme should exlain in detail the workings of the program and also the outputs generated by the program.
 - Due to abscence of gitignore, all the binaries and logs that would be generated by the program can very easily be commited to the repository unless specifically not staged, which is very error prone and has a chance to make the reposity messy.
